CSS Custom Properties (Variables)

CSS variables let you store values once and reuse them everywhere. Change one line to retheme your entire site. They cascade and inherit just like other CSS properties.

Declaring and Using Variables
/* Declare in :root to make globally available */
:root {
  --primary: #e8401c;
  --secondary: #1c6fe8;
  --text: #0d0d0d;
  --bg: #f5f2eb;
  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 32px;
  --radius: 8px;
  --font-body: 'DM Sans', sans-serif;
}

/* Use with var() */
.card {
  background: var(--bg);
  color: var(--text);
  padding: var(--space-md);
  border-radius: var(--radius);
}

/* var() fallback (if variable isn't defined) */
.button {
  background: var(--accent, #333); /* #333 is fallback */
}

Local Scope — Override Per Component

Variables can be redefined within a component, overriding the global value just for that subtree.

:root { --card-border: #ddd; }

/* Override locally */
.danger-card {
  --card-border: #e8401c; /* Only applies inside .danger-card */
}
.card {
  border: 2px solid var(--card-border);
}

/* Specificity: 0,0,0,1 — element */

Triangle Trick Explained

CSS triangles use a zero-size element with colored borders. Only one border is visible — the others are transparent.

/* Triangle pointing up */
.triangle-up {
  width: 0;
  height: 0;
  border-left: 30px solid transparent;
  border-right: 30px solid transparent;
  border-bottom: 50px solid red;
}

/* Triangle pointing right */
.triangle-right {
  width: 0;
  height: 0;
  border-top: 30px solid transparent;
  border-bottom: 30px solid transparent;
  border-left: 50px solid blue;
}

More Advanced Techniques

CSS :has() — The Parent Selector

:has() is a game-changer — it lets you select a parent based on its children. Finally, a parent selector!

/* Style a card if it contains an img */
.card:has(img) {
  padding: 0; /* Remove padding for image cards */
}

/* Style a form if it has an invalid input */
.form:has(input:invalid) {
  border-color: red;
}

/* Style a li if it has a nested ul */
li:has(ul) > a {
  font-weight: bold;
}

Dark Mode with prefers-color-scheme

Detect and respond to the user's system dark mode preference — no JavaScript needed.

:root {
  --bg: #f5f2eb;
  --text: #0d0d0d;
  --card-bg: white;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #0d0d0d;
    --text: #f5f2eb;
    --card-bg: #1a1a1a;
  }
  /* All elements using var(--bg) and var(--text)
     automatically switch! No selector changes needed. */
}

Scroll Snap

CSS Scroll Snap makes scrollable containers snap to defined positions — great for carousels, full-screen sections, or page sections. Pure CSS, no JS.

/* Container */
.scroll-container {
  overflow-x: scroll;
  scroll-snap-type: x mandatory;
  display: flex;
  gap: 16px;
}

/* Each snapping child */
.scroll-item {
  scroll-snap-align: start;
  flex-shrink: 0;
  width: 80%;
}

CSS Custom Properties — calc() Power

Combine calc() with custom properties for powerful, maintainable math-based layouts.

:root {
  --columns: 3;
  --gap: 16px;
}

.grid-item {
  /* Each item is 1/n of container minus gaps */
  width: calc((100% - (var(--columns) - 1) * var(--gap)) / var(--columns));
}

/* Responsive: change just --columns */
@media (max-width: 768px) {
  :root { --columns: 2; }
}
@media (max-width: 480px) {
  :root { --columns: 1; }
}
