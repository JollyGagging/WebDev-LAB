Animations & Transitions

Make things move. CSS transitions for smooth state changes, @keyframes for full animation sequences, and transforms for repositioning elements — all without a single line of JavaScript.

01

CSS Transitions

The transition property smoothly animates a CSS value from one state to another. It's most commonly triggered by :hover, :focus, or adding/removing a class.

Syntax: transition: property duration timing-function delay;
Example: transition: background-color 0.3s ease;

Writing Your Own @keyframes
/* Define the animation */
@keyframes my-fade-in {
  from {              /* 0% start state */
    opacity: 0;
    transform: translateY(30px);
  }
  to {                /* 100% end state */
    opacity: 1;
    transform: translateY(0);
  }
}

/* Multi-step example */
@keyframes traffic-light {
  0%   { background: red; }
  33%  { background: orange; }
  66%  { background: green; }
  100% { background: red; }
}

/* Apply it */
.my-element {
  animation: my-fade-in 0.6s ease-out forwards;
  /*         name       dur  timing    fill-mode */
}

Performance & Best Practices

⚡ Performance Tip: Only animate transform and opacity for smooth 60fps. Animating width, height, top, left, or margin triggers layout recalculations and causes jank.
GPU-Friendly vs Layout-Triggering
✅ Performant
/* GPU-accelerated — no layout reflow */
.smooth {
  transition: transform 0.3s, opacity 0.3s;
}
.smooth:hover {
  transform: translateY(-4px);
  opacity: 0.8;
}
Hover (smooth)
⚠️ Avoid in Animations
/* Triggers layout recalculation */
.janky {
  transition: margin-top 0.3s, width 0.3s;
}
.janky:hover {
  margin-top: -4px;
  width: 110%;
}
Hover (janky)
will-change Hint
/* Tell the browser to prep GPU layer ahead of time */
.animated-element {
  will-change: transform, opacity;
}

/* Only use on elements you know will animate.
   Don't use on everything — it uses extra memory. */
Respecting User Preferences — prefers-reduced-motion
Some users have vestibular disorders or motion sensitivity and prefer reduced animations. Always wrap heavy animations in this media query.
/* Default: animate freely */
.hero-element {
  animation: float 3s ease infinite;
}

/* Respect system preference */
@media (prefers-reduced-motion: reduce) {
  .hero-element {
    animation: none; /* or a very subtle fade */
  }
  * {
    transition-duration: 0.01ms !important;
    animation-duration: 0.01ms !important;
  }
}
🎯 Rule of Thumb: Animations should take 150–300ms for UI feedback (hovers, clicks). Decorative animations can be 1–3s. Anything longer than 5s should loop or be optional.
