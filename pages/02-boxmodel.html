The Box Model

Every element in HTML is a rectangular box. Understanding margin, padding, border, and content is the single most important concept in CSS layout.

Home › Typography › Box Model

2.1

Understanding The Box Model

Every element is a box with four layers: content, padding, border, and margin. The browser draws them from inside out.

📦

box-sizing: content-box (default) — width/height = content only
box-sizing: border-box ✓ — width/height includes padding + border. Almost every modern project uses *, *::before, *::after { box-sizing: border-box; } 
/* The most important CSS reset line */
*, *::before, *::after {
  box-sizing: border-box;
}

.my-box {
  width: 300px;    /* With border-box: total width is 300px */
  padding: 20px;   /* Eating INTO the 300px */
  border: 2px solid black; /* Also eating in */
  margin: 16px;    /* Space OUTSIDE the box — not part of width */
}

2.2

Margin

Margin creates space outside the border. Adjacent vertical margins collapse to the larger of the two — this is called "margin collapsing".

/* Center horizontally — must have width set! */
margin: 0 auto;

/* Negative margin — pulls elements closer */
margin-top: -8px;

2.6

Overflow

overflow controls what happens when content is bigger than its container. Values: visible, hidden, scroll, auto.

📤

Overflow Lab

overflow
overflow: visible (default)

Content spills outside the box when it's too big. You can SEE it overflow.

overflow: hidden

Content is clipped. You cannot see what's cut off. This is very useful for image containers and card thumbnails.

overflow: scroll

A scrollbar always appears, even if content fits. You can scroll to see everything. This works for both X and Y axes.

overflow: auto

Scrollbar only appears when needed. This is almost always what you want instead of scroll. Much cleaner on short content.

overflow-x: hidden (no horiz scroll)

You can scroll vertically but not horizontally. Great for preventing unwanted horizontal scrollbars on mobile. This is content to scroll.

text-overflow: ellipsis
This very long piece of text will be cut off with an ellipsis at the end because we use text-overflow: ellipsis
