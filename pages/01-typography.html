1.3

Font Size

CSS has many size units. rem is relative to the root font size (16px by default). em is relative to the parent. px is fixed. vw is relative to viewport width.

📏

Font Size Scale

font-size
0.75rem (12px) The quick brown fox
0.875rem (14px) The quick brown fox
1rem (16px) The quick brown fox
1.25rem (20px) The quick brown fox
1.5rem (24px) The quick brown fox
1.875rem (30px) Quick brown fox
2.25rem (36px) Quick fox
3rem (48px) Fox
4rem (64px) Aa
3vw Scales with window width
clamp(1rem,3vw,2.5rem) Fluid — resize the window!

Text Shadow & Gradient Text

text-shadow: x y blur color. Stack multiple shadows with commas. Gradient text uses background-clip: text.

💫

⚠️
Gradient text requires -webkit-background-clip: text AND -webkit-text-fill-color: transparent for broad browser support. Always add both prefixed and unprefixed versions.
