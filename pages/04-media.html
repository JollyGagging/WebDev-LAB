4.1

Inserting an Image

The <img> tag is self-closing. Always include alt text for accessibility and SEO. Use relative paths for local images.

🖼️

The <img> Tag

img · alt · src
✏️
To change the image: Replace the src URL in the HTML below with any image URL or relative path to a file in your project folder (e.g. src="../assets/my-photo.jpg").

Photo from Unsplash — change the src to swap this out!

<!-- Minimum required -->
<img src="photo.jpg" alt="Description of image">

<!-- Full best practice -->
<img
  src="https://example.com/photo.jpg"
  alt="A developer's laptop with code on screen"
  width="600"     <!-- prevents CLS (see Module 06) -->
  height="400"    <!-- prevents CLS -->
  loading="lazy"  <!-- only loads when visible -->
>

<!-- Local file paths -->
<img src="./images/hero.jpg" alt="Hero image">
<img src="../assets/logo.png" alt="Company logo">
⚠️
Never leave alt="" empty on meaningful images — this hurts accessibility and SEO. Only leave it empty for purely decorative images.

4.2

object-fit — Controlling How Images Fill Their Container

When you give an image a fixed width AND height, object-fit controls how the image fills that box without distorting.

📐

object-fit Gallery

object-fit
object-fit: cover ✓ (most common)

Fills container, crops excess. No distortion.

object-fit: contain

Shows entire image, may leave gaps.

object-fit: fill (distorts!)

Stretches to fill. Usually avoid this.

object-fit: scale-down

Smaller of "none" or "contain".

/* Always use cover for thumbnails, cards, hero images */
.card-thumbnail {
  width: 100%;
  height: 220px;
  object-fit: cover;

  /* Control focal point */
  object-position: center center; /* default */
  object-position: top;           /* show top of image */
  object-position: 30% 20%;       /* custom position */
}

4.5

HTML Video

The <video> element embeds video directly. Key attributes: controls, autoplay, muted, loop, poster. Always include multiple <source> formats.

▶️

Native HTML Video — All Attributes Explained

video · controls · autoplay · loop

Example 1: Standard video with controls

Example 2: Autoplay + muted + loop (background video pattern)

Autoplays, muted, loops infinitely. Add playsinline for iOS.

<!-- Standard video with controls -->
<video controls width="100%" poster="thumbnail.jpg">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  Your browser doesn't support video.
</video>

<!-- Background video (autoplay must be muted in browsers) -->
<video autoplay muted loop playsinline>
  <source src="bg-video.mp4" type="video/mp4">
</video>

<!-- Attributes reference -->
controls     → shows browser play/pause/volume UI
autoplay     → starts playing immediately (must be muted)
muted        → no audio (required for autoplay)
loop         → replays when finished
playsinline  → plays inline on iOS (not fullscreen)
poster       → image shown before video plays
preload      → "auto" | "metadata" | "none"
width/height → size (or use CSS)

Embedding YouTube / Vimeo with iframe

iframe · aspect-ratio
✏️
Replace dQw4w9WgXcQ with any YouTube video ID to change the video.
<!-- Responsive YouTube embed — the modern way -->
<div style="aspect-ratio: 16/9;">
  <iframe
    width="100%"
    height="100%"
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="Video title"
    frameborder="0"
    allowfullscreen
    loading="lazy"
  ></iframe>
</div>

<!-- aspect-ratio keeps 16:9 at any width — no padding hack needed -->

<!-- Old padding-bottom hack (still works but less clean) -->
<div style="position:relative; padding-bottom:56.25%; height:0;">
  <iframe style="position:absolute; top:0; left:0; width:100%; height:100%;" ...></iframe>
</div>

aspect-ratio — The Modern Way
