Module 03

Layouts:
Flex & Grid

Flexbox for one-dimensional alignment. CSS Grid for two-dimensional layouts. Together, these two tools can build any page you can imagine.

Home › Box Model › Layouts

3.1

The display Property

Every element has a default display value. block takes full width. inline flows with text. inline-block is both. none hides it completely.

🟦

display Values

display

display: block (each takes full width, stacks vertically)

Block element #1
Block element #2

display: inline (flows with text, no width/height)

Inline #1 Inline #2 Inline #3 — these flow like words in a sentence

display: inline-block (can set width/height, flows inline)

IB #1 IB #2 IB #3 
/* Common display values */
display: block;         /* Full width, stacks */
display: inline;        /* Flows with text */
display: inline-block;  /* Inline but can set width/height */
display: flex;          /* Flexbox container */
display: grid;          /* Grid container */
display: none;          /* Completely hidden (removed from flow) */

/* vs visibility: hidden — hides but keeps the space */
visibility: hidden;

Grid Spanning — grid-column & grid-row

grid-column · grid-row

Spans 3 columns (grid-column: span 3)

Normal

Spans 2 columns
Normal
/* Spanning */
.item { grid-column: span 2; }    /* spans 2 cols */
.item { grid-row: span 2; }       /* spans 2 rows */

/* Explicit placement */
.item { grid-column: 1 / 3; }    /* from line 1 to line 3 */
.item { grid-column: 1 / -1; }   /* from first to last line */
.item { grid-row: 2 / 4; }

/* Shorthand */
.item { grid-area: 2 / 1 / 4 / 3; } /* row-start / col-start / row-end / col-end */

3.4

Positioning

static (default), relative (offset from own position), absolute (relative to nearest positioned ancestor), fixed (relative to viewport), sticky (relative until scroll threshold).

📍

Position Types

position
static (normal flow)
relative (moved 20px from normal)
absolute (top: 20px right: 20px)
abs bottom-right
abs top-left
/* static — default, ignores top/left/right/bottom */
position: static;

/* relative — offset from normal position */
position: relative;
top: 20px;  left: 10px;

/* absolute — removed from flow, placed relative to nearest
   positioned (non-static) ancestor */
position: absolute;
top: 0;  right: 0;

/* fixed — stays in same spot when scrolling */
position: fixed;
bottom: 20px;  right: 20px;

/* sticky — normal flow until scroll position hit */
position: sticky;
top: 0;  /* Sticks when it reaches the top */

z-index — Stacking Order:

z-index: 0
z-index: 1
z-index: 2
z-index: 3 (on top)
⚠️
z-index only works on positioned elements (relative, absolute, fixed, or sticky). It has no effect on static elements.
