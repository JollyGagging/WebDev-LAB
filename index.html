🔧 How to Use This Lab

  1. 1
    Open this folder in VS Code Right-click the webdev-lab folder → "Open with Code"
  2. 2
    Open any .html file and its matching .css file side by side Use the split-editor view (Ctrl+\ or Cmd+\)
  3. 3
    Install "Live Server" extension and hit Go Live Your browser will auto-refresh every time you save a file
  4. 4
    Find any ✏️ Practice Zone box and change the values Every property shown has a comment telling you what to try changing
  5. 5
    Break things. Fix them. That's the whole plan. Use git to save snapshots of your progress. Push to GitHub Pages to share!
